回放说明与诊断

项目插件从用户指定的 result.json、trace.jsonl 与对应版本场景生成。回放无需联网，不运行仿真，也不更改裁判结果。

视角与逐帧

默认左键拖拽平移，右键或 Shift 拖拽旋转；也可切换“平移 / 旋转”。手动拖动会退出自动导览，避免镜头被拉回。蓝方固定表示进攻、红方固定表示防守（侦察与应急显示各自任务角色），不随参赛身份或视角交换。阵营视角汇总对应阵营各控制器的已记录授权观测，只画己方观测实体与传感器估计触点，不用裁判位置补造敌人；汇总不代表每个控制器都知道全部队友信息。未记录某方观测时明确留空。“双方上帝视角”供赛后诊断；HTML 中含赛后真值，按钮不是访问权限隔离。

新测试默认记录初始帧与每个仿真 tick 后的双方状态、原生导弹位置及各控制器观测。上一帧 / 下一帧、逐帧模式和 JSONL 下载均使用原始记录；平滑显示仅插值画面，不改变下载数据。旧日志只能按已有观测样本步进，不能导出不存在的逐 tick 真值。tick 是仿真步，实际秒数按记录的 tick_seconds 换算。

REC / ER 海图背景

原调优场景没有地图绑定。此版引用 IE 同源威海海岸线、闭合岛屿和港区边界作为显示背景，保持米制坐标原样；不是原场景的真实地理配准，也没有参与旧局碰撞、遮挡或评分。默认“海岸场景”同时展示任务区和附近海岛；“任务近景”查看轨迹细节，“海岸全图”查看完整背景。已有原生地图的 IE 回放保持原绑定。

如何检查

场景卡片和策略 / 种子按钮切换对局；时间轴、关键阶段、事件列表均可跳转。支持旋转、缩放、俯视、跟随、倍速与全屏。设施受损可直接定位；任务失败不一定代表设施被突破。

记录点、平滑与阵营视角

实线航迹逐个连接已有位置记录，小点表示记录位置。平滑处理默认为关，开启后只改变显示曲线，小点与原始导出不变；逐帧模式始终停在原始记录。缺少完整记录的实体使用虚线连接稀疏锚点，不能当作真实逐帧航迹。

阵营视角显示本方全部在场单位和本方导弹；敌方只显示实际探测到的估计触点。每条测量从该控制器首次实际收到时显示一个仿真 tick，持续探测则持续可见，周期探测则按记录周期显隐，不以旧触点冒充实时位置。空中 / 水面外形按估计高度示意，不反推真实身份。阵营视角是赛后全队检查，不代表单个控制器输入。

有在飞导弹记录时连接真实弹道点；历史局没有在飞位置时，阵营视角只展示本方发射及短距离初段示意，不画通往隐藏目标的完整路线；上帝视角仍可查看发射、命中凭据之间的弹道示意。模型、高度和光效经过放大。

导弹速度与范围

默认按 1× 仿真时间播放，精华导览默认关闭；可选 0.25× 或 0.5× 慢放观察导弹。选择实体可在参数栏查看本局绑定武器的弹种、巡航水平速度与初速。不同弹种保留各自装备参数，播放器不按阵营加速导弹。范围圈默认隐藏，地图右上“范围圈”可切换隐藏、仅所选或全部；实体失能、未入场或当前视角无权限时不画其探测圈。

探测与武器范围

地图右上“范围圈”或“图层设置”均可打开开关，全屏时也可使用。默认隐藏；选“仅所选”后点选单元，或选“全部”查看所有有权限的单元。无人船、无人机、岸基 / 固定雷达分别开关；也可查看光电 / 其他探测、武器最大与最小射距，显示模式切换保留类别选择。圈线采用阵营颜色；实线为雷达，虚线为其他探测与武器。点“查看所选范围”才会调整镜头，普通开关不改变镜头。参数来自本局绑定资源，旧结果仅在原版本运行时摘要一致时补取。圈是标称三维距离在水平地图上的上界参考，不代表已探测、必定命中或当前可用；没有重建天气、组件压制、能量、目标高度与射界等时变限制。旧式 low_altitude_range_m 字段不单独解释为当前引擎有效低空圈；显式 altitude_range_profile 才列出低空参数。阵营视角仅显示本方范围，不从敌方触点反推真实装备。

海岸线与大陆架

完整海岸线从地图资源的 visualization_source 读取，核对原始文件 SHA-256，并按引擎相同坐标原点投影。包括外围大陆海岸、周边岛礁与港区边界；原本开放的海岸路径保持开放，不能闭合填成陆地。任务 land_regions 仅保留为碰撞数据，不绘制多边形边框、填色或派生近岸圈。点“海岸全图”查看完整区域，点“战区”返回交战范围。当前没有真实水深资料，近岸色带仅为示意，不能称为真实大陆架或等深线，也不参与导航、碰撞或评分。

不完整测试

截断探针、算法异常或基础设施异常保留原状态；缺少终局快照时仅显示最后已知位置，不能推断终局成败。侦察与应急响应提供任务区域、已投递通知 / 报告和逐时刻裁判指标。实际收到消息不等于裁判已认可任务完成；抵达不等于物理救援。
